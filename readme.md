# Petly New CSS

A modern, static, bilingual front-end website for Petly Veterinary Clinic.

This version is a standalone front-end rebuild located inside the `petly_new_css/` directory. It is fully separated from the old PHP project and focuses on clean UI, responsive layouts, bilingual support, and improved mobile experience.

---

## Overview

`petly_new_css/` is a complete static front-end implementation.

It does **not** include:

- PHP
- Database
- Admin dashboard
- Authentication / login
- Booking system
- E-commerce / store
- Backend logic

The goal of this version is to provide a polished, fast, responsive, and bilingual user interface with full English and Arabic support, including proper RTL layout for Arabic pages.
